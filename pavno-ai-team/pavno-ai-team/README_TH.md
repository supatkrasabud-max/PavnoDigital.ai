# บอท LINE ของ PAVNO (Ami + Yuki): คู่มือติดตั้ง

คุยกับทีม AI ของบริษัทผ่าน LINE ได้ทั้งแชต 1:1 และกลุ่ม

- **Ami (ผู้ช่วย CEO):** รับคำสั่ง แบ่งงานให้ฝ่ายสินค้า การตลาด บริการลูกค้า และ**ฝ่ายวางแผนธุรกิจ** แล้วสรุปผลกลับมา
- **Yuki (ฝ่ายการเงิน):**
  - บันทึกรายรับ รายจ่าย เงินเก็บ และเงินลงทุน ลงชีต **"PAVNO บัญชี"** ชีตเดียวกับเว็บแอป Yuki Ledger
  - ตั้งเป้ารายรับ กำไร และเงินเก็บ
  - ส่งรายงานอัตโนมัติ **ทุกเช้า 08:00, ทุกวันจันทร์ 09:00 และทุกวันที่ 1 เวลา 09:00**
- **Stripe:** เมื่อมีลูกค้าจ่ายเงินบนเว็บ ระบบบันทึกรายรับให้เอง

## ค่าใช้จ่าย (ประมาณการ)

| รายการ | ค่าใช้จ่าย |
|---|---|
| Claude API | 300–1,000 บาท/เดือน ขึ้นกับจำนวนข้อความ ตั้งเพดานใช้จ่ายได้ที่ console.anthropic.com |
| LINE OA แพ็กเกจฟรี | 0 บาท (ส่งข้อความแบบ push ได้ 300 ข้อความ/เดือน รายงานอัตโนมัติใช้ประมาณ 35 ข้อความ ส่วนการตอบกลับไม่นับโควตา) |
| Cloud Run, Secret Manager, Cloud Scheduler | ปกติอยู่ในโควตาฟรี (Scheduler ฟรี 3 งาน) |

## ขั้นที่ 1: สร้างคีย์ Claude API (ทำเอง ประมาณ 5 นาที)

1. เข้า https://console.anthropic.com แล้วสมัครหรือล็อกอิน
2. ไปที่ **Billing** เติมเครดิต แล้วตั้ง **Monthly spend limit** เช่น $20
3. ไปที่ **API Keys > Create Key** แล้วคัดลอกคีย์ไว้ ห้ามส่งคีย์นี้ในแชตใด ๆ

## ขั้นที่ 2: สร้างบอท LINE (ทำเอง ประมาณ 10 นาที)

1. สร้าง LINE Official Account (แพ็กเกจฟรี) ที่ https://manager.line.biz
2. ใน OA Manager ไปที่ **ตั้งค่า > Messaging API** แล้วกด **เปิดใช้ Messaging API**
3. ใน **ตั้งค่า > การตั้งค่าการตอบกลับ** ให้**ปิด**ข้อความตอบกลับอัตโนมัติ และ**เปิด** Webhook
4. ถ้าจะใช้กลุ่ม ไปที่ **ตั้งค่า > บัญชี** แล้วเปิด **อนุญาตให้บัญชีเข้าร่วมแชทกลุ่ม**
5. เข้า https://developers.line.biz แล้วเลือก Channel ของบอท
   - แท็บ **Basic settings:** คัดลอก **Channel secret**
   - แท็บ **Messaging API:** กด Issue **Channel access token**

## ขั้นที่ 3: ติดตั้งบน Google Cloud (ประมาณ 10 นาที)

1. เปิด https://console.cloud.google.com แล้วเลือกโปรเจกต์ที่ผูกบัตรไว้
2. กดไอคอน **Cloud Shell** (`>_`) มุมขวาบน
3. วางคำสั่งนี้ทีละบรรทัด

```bash
git clone https://github.com/supatkrasabud-max/PavnoDigital.ai.git
cd PavnoDigital.ai/pavno-ai-team/pavno-ai-team
bash deploy/cloudshell-setup.sh
```

สคริปต์จะทำงานตามลำดับนี้:

1. รันเทสต์ทั้งหมด ถ้าเทสต์ไม่ผ่าน จะหยุดก่อนติดตั้ง
2. เปิดใช้บริการ Google Cloud ที่บอทต้องใช้
3. สร้าง service account สำหรับอ่านและเขียน Google Sheet
4. ให้คุณวางคีย์ทีละตัว ตัวอักษรจะไม่แสดงบนจอ แล้วเก็บไว้ใน **Secret Manager** คีย์จะไม่อยู่ในโค้ดหรือในไฟล์ใด ๆ
5. นำบอทขึ้น Cloud Run
6. ตั้งรายงานอัตโนมัติรายวัน รายสัปดาห์ และรายเดือน

## ขั้นที่ 4: ทำต่อหลังสคริปต์จบ

สคริปต์จะแสดงข้อมูลที่ต้องใช้ให้ทั้งหมด

1. **แชร์ Google Sheet "PAVNO บัญชี"** ให้อีเมล service account ที่สคริปต์แสดง เป็น **Editor**
2. **ตั้ง Webhook URL:** ไปที่ LINE Developers > Messaging API > Webhook URL ใส่ `https://…run.app/callback` แล้วกด **Verify** และเปิด **Use webhook**
3. **ตั้ง CEO_USER_ID ทันที:** เพิ่มบอทเป็นเพื่อน พิมพ์ `myid` แล้วรันคำสั่ง `gcloud run services update …` ที่สคริปต์แสดง
   - ก่อนตั้งค่านี้ ใครที่แอดบอทก็คุยกับบอทได้
   - หลังตั้งแล้ว บอทจะตอบเฉพาะคุณ
4. **ถ้าใช้กลุ่ม (ไม่บังคับ):** เชิญบอทเข้ากลุ่ม พิมพ์ `groupid` แล้วตั้ง `LINE_GROUP_ID` ด้วยวิธีเดียวกับข้อ 3
   - ถ้าจะให้คนอื่นในกลุ่มสั่งงานได้ ให้ตั้ง `ALLOWED_USER_IDS` ด้วย

**อัปเดตโค้ดครั้งต่อไป:** เปิด Cloud Shell แล้วรัน

```bash
cd PavnoDigital.ai && git pull && cd pavno-ai-team/pavno-ai-team && bash deploy/cloudshell-setup.sh
```

ระบบจะไม่ถามคีย์ซ้ำ ถ้าต้องการเปลี่ยนคีย์ ให้รันด้วย `FORCE_ASK=1`

## ขั้นที่ 5: เชื่อม Stripe (ทำหลังเปิดรับเงินแล้ว)

1. ไปที่ Stripe Dashboard > Developers > **Webhooks** > Add endpoint
2. ใส่ URL เป็น `https://…run.app/stripe/webhook`
3. เลือก event `checkout.session.completed` และ `checkout.session.async_payment_succeeded`
4. คัดลอก **Signing secret** แล้วรันคำสั่งนี้ใน Cloud Shell วางค่าตอนที่ระบบถาม

```bash
read -rs v && printf '%s' "$v" | gcloud secrets versions add STRIPE_WEBHOOK_SECRET --data-file=-
```

## วิธีคุยกับบอท

ในแชต 1:1 พิมพ์ได้เลย ไม่ต้องขึ้นต้นด้วยชื่อ ส่วนในกลุ่มให้ขึ้นต้นข้อความด้วย **Ami** หรือ **Yuki**

| พิมพ์ | ผลลัพธ์ |
|---|---|
| `วิธีใช้` | ดูคำสั่งทั้งหมด |
| `สรุปวันนี้` / `เป้า` / `รายงาน` / `สรุปเดือนนี้` | ตัวเลขทันที ไม่เสียค่า AI |
| `Yuki ได้ค่าคอม Shopee 1,250 บาท` | บันทึกรายรับ ช่องทาง Shopee |
| `Yuki จ่ายค่าโฆษณา TikTok 300` | บันทึกรายจ่าย และเตือนเมื่อเกินงบ |
| `Yuki โอนเข้าเงินเก็บบริษัท 2,000` | บันทึกเงินเก็บ |
| `Yuki ตั้งเป้าทุกเดือน รายรับ 30,000 กำไร 15,000 เงินเก็บ 5,000` | ตั้งเป้ารายเดือน |
| `Yuki เพิ่มช่องทาง Lazada เป้า 3,000` | เพิ่มช่องทางรายได้ใหม่ ไม่จำกัดจำนวน |
| `Ami วางแผน 90 วันให้รายได้ถึง 50,000 ต่อเดือน` | ฝ่ายวางแผนใช้ตัวเลขจริงจาก Yuki วางแผนเป็นรายสัปดาห์ |
| `Ami ทำแผนคอนเทนต์ TikTok สัปดาห์นี้` | ฝ่ายการตลาดวางแผน และขออนุมัติงบถ้าต้องใช้เงิน |
| `อนุมัติ A1B2` / `ไม่อนุมัติ A1B2` | ตอบคำขอใช้เงิน |

## ข้อจำกัดที่ควรรู้

- **บอทไม่จ่ายเงินจริง:** บอทเข้าบัญชีธนาคารไม่ได้ คุณกดจ่ายเองทุกครั้ง แล้วแจ้ง Yuki ให้บันทึก
- **บอทไม่ใช่ Claude Code:** บอทแก้เว็บหรือทำไฟล์ในคอมไม่ได้ งานลักษณะนี้ Ami จะสรุปเป็นรายการให้คุณนำไปสั่ง Claude Code ต่อ
- **คำแนะนำการลงทุน:** แผนการเงินแนะนำเฉพาะการลงทุนในธุรกิจของบริษัท ไม่แนะนำหุ้น กองทุน หรือคริปโตรายตัว
- **บัญชีตามกฎหมาย:** Yuki ทำบัญชีบริหารเท่านั้น งบการเงินตามกฎหมายต้องให้ผู้ทำบัญชีที่ขึ้นทะเบียนรับรอง
- **ความจำของบอท:** บอทจำบทสนทนาได้ประมาณ 6 รอบล่าสุด และจะลืมเมื่อเซิร์ฟเวอร์หยุดพัก แต่ข้อมูลบัญชีอยู่ในชีตเสมอ
